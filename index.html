TensorFlow et Keras : la veille qui se manipule

Six notions pour construire des modèles de Deep Learning, avec des démos à essayer pendant la réunion. Naviguez avec les flèches du clavier ou les boutons en bas.

1. TensorFlow et son rôle dans le Deep Learning

TensorFlow est une bibliothèque open source créée par Google pour calculer sur des tenseurs et entraîner des réseaux de neurones. Elle gère trois choses : les calculs (sur CPU, GPU ou TPU), la différentiation automatique (le calcul des gradients pour l’apprentissage) et le déploiement (serveur, mobile avec TF Lite, navigateur avec TF.js).

Les données circulent sous forme de tenseurs. Seule la première dimension (le lot) change avec la taille du lot.

2. Comment Keras simplifie TensorFlow

Keras est l’API de haut niveau de TensorFlow. Elle remplace la mécanique des poids, des gradients et des boucles par des briques lisibles : Dense, compile, fit. Comparez le même modèle écrit des deux façons.

5. CPU, GPU, TPU : c’est quoi ?


Ce sont trois types de processeurs qui exécutent les calculs d’un modèle. Image à retenir : le CPU est un chef cuisinier très polyvalent, le GPU est une brigade de milliers de commis qui épluchent en même temps, et le TPU est une machine conçue uniquement pour éplucher.




CPU
Central Processing Unit
Le processeur général de l’ordinateur. Il a quelques cœurs puissants, qui enchaînent des tâches variées.
Utile pour : préparer les données, la logique du programme, les petits modèles.


GPU
Graphics Processing Unit
D’abord conçu pour l’image et les jeux. Il a des milliers de petits cœurs qui font la même opération en parallèle, idéal pour les multiplications de matrices. Fabricants courants : NVIDIA (avec CUDA) et AMD.
Utile pour : entraîner la plupart des réseaux de neurones.


TPU
Tensor Processing Unit
Une puce créée par Google spécialement pour les calculs sur tenseurs. Elle est très efficace sur les gros modèles, mais moins flexible qu’un GPU. On l’utilise surtout avec TensorFlow et JAX.
Utile pour : de très gros entraînements, sur Google Cloud ou Google Colab.









5. CPU et GPU en action


Un CPU a peu de cœurs, très polyvalents. Un GPU en a des milliers, plus simples, qui font la même opération en parallèle : c’est ce qu’il faut pour multiplier de grosses matrices. Lancez la course : chaque case est un calcul à effectuer.

6. C’est quoi PyTorch ?


PyTorch est une bibliothèque open source de Deep Learning, lancée en 2016 par Meta (alors Facebook AI Research) et aujourd’hui gérée par la PyTorch Foundation. Elle est très appréciée en recherche car son code ressemble à du Python ordinaire.




Tenseurs
torch.Tensor ressemble à un tableau NumPy, mais peut tourner sur GPU.


Autograd
Le calcul automatique des gradients : on appelle backward() et PyTorch fait le reste.


Graphe dynamique
Le graphe de calcul se construit pendant l’exécution, donc on peut déboguer avec print ou un débogueur classique.

Les deux frameworks font le même travail. Les différences sont surtout dans le style de code et l’écosystème.
